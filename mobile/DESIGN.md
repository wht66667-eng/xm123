# fox 安全学习
Platform: mobile-first web, Flask API, native ES modules and shared CSS primitives.
Job: select a source, look up a question, connect the school platform or obtain its page adapter.
Tone: focused, approachable, precise. System Chinese sans typography, ivory canvas, dark forest text, orange fox signature. Search is the anchor; forms and results carry the content.
Screens: library (search/source/empty/error), platform (login/captcha/activity/paper/answer/submit), tools (script download/copy/instructions).
Touch controls >=44px; bottom navigation; no invented accounts or scores. Remote account verification requires user credentials and is not part of local QA.
