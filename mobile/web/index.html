下载脚本

手机如何使用

  1. 在支持用户脚本的手机浏览器中安装用户脚本扩展。
  2. 下载脚本，将文件内容添加为新用户脚本并保存。
  3. 打开对应答题页面，点击右下角 fox，再点击开始填写。
  4. 核对答案与未匹配题目，最后自行提交。

脚本默认不匹配任何站点。先在文件头将 @match 的 example.invalid 替换为实际答题网站域名。普通手机浏览器的网页无法直接控制另一个网站。
