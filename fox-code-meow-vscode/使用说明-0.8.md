# fox 0.8 本机使用说明

## 启动与桌宠
启动交付目录内的fox狐狸娘-0.8.0.exe。若旧版仍在运行，先从旧版右键菜单退出，再打开新版。双击宠物打开助手，右键调整50%到200%尺寸、导入动作帧皮肤/PNG图集、恢复默认或开关漫步；格式见SKIN_FORMAT.md。已有用户配置保留在APPDATA/fox-code-meow，不放进源码与安装包。

## 手动AI与VS Code
小钥匙页面自行填写接口、模型、协议和密钥，保存不会发请求。只有点击聊天/解析/团队启动才请求AI。VS Code安装本机VSIX，命令面板搜索fox；可对所选代码解释并在终端查看建议，保留知识库和桌宠入口。

## 小书包与Obsidian
拖入文件或选择文件夹，资料会导入私有副本。连接Obsidian文件夹后手动同步Markdown，每批最多200篇，不修改原笔记，不执行.obsidian插件。只有显式附带资料并发起AI请求，匹配片段才会发往你配置的API。

## Agent小队
六个角色各自选择API和模型，填写密钥，保存专属skill。协调者、选中专家、审查员须分别配置；不会自动沿用其他角色密钥。选择本机三套GIS实验摘要，再输入任务，点击启动。每次最多6个请求；停止会阻止后续交接，已经开始的网络请求可能需等待返回。配置和打开页面都不请求AI。

## 从文字到GIS参数
ArcMap页面切换“空间分析”，写“铁路右侧150米圆头缓冲”或“公园200、500、1000米不融合”，点击从文字填入参数。选择完整Shapefile与新的输出路径，预览并核对坐标系、侧类型、末端及融合参数，再点击执行。解析文字本身不调用API、不写文件、不执行运算。

本机ArcPy原生数据访问仍会超时，缓冲/叠加尚未原生验收。无响应时使用停止分析；先解决ArcGIS环境问题再确认成功。MXD读取、另存及PDF导出已用真实Redlands地图验证。不能用“环境检测显示ArcInfo”代替原生计算通过。

## 电脑任务与自我优化
工作台选择指定目录，可打开/检查目录并停止本插件任务。优化先选fox源码创建独立副本，检查后手动选择单个文件交AI生成候选，审阅差异后只写入副本，重跑检查，再构建候选EXE与VSIX。不会自动覆盖正在运行版本；副本是版本隔离，不是系统沙箱，应审阅候选后再执行其测试。可恢复副本基线。

## Skill与API目录
工作台可将确认的习惯导出SKILL.md；副本检查会生成检查习惯草稿。13份高星开源skill仅导入本机知识库，没有自动运行它们的指令。小钥匙页面有免费/每日额度API目录，实际额度以账户为准；FreeLLMAPI需要自行部署网关，public-apis是目录而非统一聊天接口。

## 报告
桌面新建文件夹 (9)/ArcMap实验测试-20261102/实验报告成果内有三份各5页PDF、可编辑MD、图表、Shapefile、CSV及计算JSON。报告明确区分开源复算和ArcMap原生执行。实验一精度与正式描绘、实验二右侧圆头、全部原生GP验收仍有待补项，不应直接当作全部实验完成提交。
