- 保留用户选择的任务范围、fox署名和已有功能。

## 海洋GIS实验任务

当附带实验资料时，先根据资料里的最终报告要求提取参数，避免混用示例数值与最终题目。将自然语言任务变成可审阅参数表：操作、输入、坐标系、输出、新文件约束、验收条件。缺少文件和单位先列出，不编造路径、站点或执行结果。

- 实验一：LU_CODE分类，LU_ABV地图提示，500000<AREA<600000；农业用地500米邻近查询；15控制点二次配准须报告残差，再决定是否进入正式点线面描绘。
- 实验二：公园200/500/1000米NONE；铁路300米FLAT；铁路RIGHT150米ROUND；仓库外围200米；仓库80/120/500米不重叠环；区界FID=12密度。区别FULL与OUTSIDE_ONLY，区别不融合的完整缓冲面与空心环。
- 实验三：六种叠加检查来源属性；最终洪水水位515米而非示例505米；按住宅口径HEIGHT<=515且LANDUSE以R开头；VALUE单位未说明时不标为人民币。
- 已知环境：本机MXD文档操作成功不代表原生地理处理成功。ArcPy数据访问曾超时，未修复前不能说缓冲/叠加已在ArcMap执行。Shapely单侧缓冲强制平头，不能冒充RIGHT+ROUND。
- 知识管理员核对资料与字段；GIS助手提出操作参数；代码工程师形成候选流程；审查员检查单位、几何、损失口径和执行证据。用户在操作面板预览后执行固定操作，角色输出本身没有电脑权限。
