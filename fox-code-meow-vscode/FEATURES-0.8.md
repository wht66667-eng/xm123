# fox 0.8.0 功能总结与边界

## 桌宠
Qt透明无边框、可漫步/拖动；右键调尺寸50%–200%，导入skin.json动作帧文件夹或6行PNG图集，恢复默认，减少动画，称呼/专注输入。配置保存在本机。皮肤不含可执行脚本。

## 知识与skill
小书包支持本机文档副本、离线搜索、连接Obsidian后手动同步Markdown（每批上限200篇）。不修改原笔记，不读取.obsidian插件设置。附带资料默认关闭；手动AI解析/聊天开启辅助时会发送匹配片段。
13份高星skill来自5个仓库，已导入本机知识库；星标搜索筛选不代表全GitHub绝对排名。第三方原文未完成全部再分发许可确认，故从Git和安装包中排除，仅保存本机副本、来源元数据和许可证。知识文档不会自行执行命令。
工作台可将用户确认的习惯导出为独立SKILL.md；每次副本检查也生成一份检查习惯草稿。

## Agent小队
协调者、代码工程师、GIS助手、知识管理员、交互设计师、审查员，各自API配置与skill，密钥DPAPI加密。流程为协调者→选中专家→审查员，每次最多6个请求。不自行调用电脑工具；生成的方案由用户在操作面板预览执行。停止后不发新请求，当前网络请求可能仍需等待结束。
参考CrewAI角色分工、AutoGen交接、LangGraph状态记录的设计，独立实现，未声称引入这些框架。

## 电脑任务与ArcMap
工作台提供指定目录检查（最多500文件）和打开目录，不提供无边界鼠标/键盘自动控制或任意生成命令执行。
ArcMap快捷方式目标C:/Program Files (x86)/ArcGIS/Desktop10.8/bin/ArcMap.exe；ArcPy使用C:/Python27/ArcGIS10.8/python.exe隔离运行。支持启动、检测、读磁盘MXD图层与数据框、另存副本、导出PDF。预览后才执行，输出必须是新文件。CURRENT只在ArcMap内部可用，外部桥接不用CURRENT。不修改当前未保存地图，不提权改安装文件。中止仅停止本插件任务进程；中断写出可能留下部分输出。
本机安装模板实测读取/另存/PDF成功，ArcPy仍输出936代码页缺失警告；未假定所有真实地图、受保护数据源和中文字形都已验证。

## 自我优化
选择fox源码目录→复制到独立版本目录→执行Node测试和Python语法检查→手动发送所选单个文件给AI生成候选→审阅→仅写入副本→重新检查→构建候选EXE/VSIX（构建包含独立EXE自检）。可停止进程树、恢复副本基线。不会自动替换正在运行的版本，保留旧版用于回滚。副本是版本隔离，不是操作系统沙箱；执行测试前应审阅候选代码。
候选安装包生成后由用户选择安装，原项目不自动修改。

## API与VS Code
保留Chat Completions、Responses、Messages三协议和用户填写地址/模型/密钥。免费目录包括OpenRouter免费模型、Groq免费层、Gemini免费层、FreeLLMAPI自建网关、本机Ollama及public-apis目录入口。额度、地区和模型权限以官方账户为准；不内置共享密钥，不通过换账户绕过额度。public-apis不是统一聊天API。
VS Code仍可选区/逐行/函数解释、提出建议、终端输出、气泡聊天、知识库和桌宠启动。打开页面不自动请求AI。


## 海洋GIS实验资料与文字参数
本机多Agent已导入三套实验摘要和数值表，可在团队任务中选择实验；仅启动时把该摘要交给各角色。原PDF、私人目录与计算数据不进Git或安装包。文字填参数入口只在本机解析固定操作、米制距离及侧/末端/融合参数，用户选择数据和新输出后预览执行。
真实Redlands地图5图层均未断链，另存和导出PDF成功；本机ArcPy的Exists、SearchCursor、Buffer及workspace数据访问发生超时，包括纯英文路径和隔离配置对照。因此新增缓冲/六种叠加接口不能标为本机原生验收成功。实验报告使用独立开源复算，明确保留原生验收和配准/正式描绘缺口。
