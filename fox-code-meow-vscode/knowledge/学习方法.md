# 从入口理解项目
先识别语言、运行环境、入口和依赖，再沿输入、处理、输出逐步追踪。浏览器扩展的manifest定义注入与权限，Python入口可能在导入时就运行；不要为了读懂项目直接执行未知main.py或安装器。

# 逐行读代码的小步骤
先看一段代码接收什么输入，再看变量如何变化、分支如何选择、循环何时结束，最后看输出及外部副作用。括号和缩进属于结构，理解结构后再关注具体表达式。跨文件调用缺少实现时应明确标成未知，而不是编造。

# 讲解和建议不同
讲解说明原代码如何工作；建议说明在保持目标行为时可以怎样改善，并标明证据、收益和风险。建议中的示例没有被执行或自动应用。先在小样例里验证，再考虑修改正式项目。

# 本地知识库的使用
内置资料和你导入的Markdown/TXT都可在本机按关键词检索。资料只是参考，不保证适用于当前代码。引用时应带来源名称；不同学校平台、认证方式和题库答案格式不可混为一谈。
