# Python函数、参数和返回值
函数用def声明，把重复步骤封装成可调用单元。参数由调用者传入，return返回结果并结束本次函数执行；没有显式return时返回None。局部变量通常只在函数作用域内有效，不能把打印输出等同于返回值。

# JavaScript异步与Promise
async函数总是返回Promise，await等待该Promise完成；它不会把整个JavaScript线程阻塞成同步线程。try/catch可以处理await抛出的错误，但不能自动处理没有await也没有catch的独立Promise。异步网络操作应有超时、取消和明确错误状态。

# HTTP API请求与认证
GET通常用于读取，POST常用于提交数据，但最终副作用由服务端定义。HTTP 200不等于业务成功，还应校验响应中的业务状态和数据结构。Token/Cookie/API Key是凭据，不能出现在公开源码或日志中。改变API服务地址时不能复用另一个服务的密钥。

# SQLite事务与连接
使用参数占位符传递用户输入，避免拼接SQL。事务可以让一组写操作要么全部提交要么回滚。Python的with sqlite3.connect(...)默认管理事务，但不自动关闭连接，应显式close或使用closing。多个线程/进程写入需要了解SQLite锁和超时。

# 错误处理与重试
错误处理应区分参数错误、认证失败、权限不足、网络超时和服务端业务失败。读请求可以有受限重试；写请求在结果不确定时盲目重试可能重复提交。不能用except后直接忽略所有异常来制造成功状态。

# 代码建议与验证
提出改进前先理解原行为和调用方，不要把主观风格当成错误。修复应说明触发条件、问题证据、行为变化和验证方法。静态分析和AI解释不能证明代码在真实环境已经运行正确。

# 秘密管理与最少上下文
.env、私钥、真实账号、密码、Cookie和API Key不应上传到公开仓库。只发送为本次讲解必要的代码；自动遮盖规则无法识别所有秘密。扩展的SecretStorage用于保存密钥，本地Markdown知识库是普通文本，不能当成密码保险箱。
