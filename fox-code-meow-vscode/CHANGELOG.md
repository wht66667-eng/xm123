# 更新记录

## 0.4.0 · 狐狸娘动画版
- 原创形象方向的透明狐狸娘图集：6组动作，36帧。
- 桌面摸摸/投喂/休息/学习状态分别触发害羞、跳跃、困倦和思考。
- VS Code陪伴小屋同步采用狐狸娘逐帧动画；支持系统减少动画。
- 保留用户自行配置API、SecretStorage、手动解析与建议、本地知识库、主动聊天。

## 本次维护优化
- 桌面状态文件读取由每秒10次降为最多每秒1次。
- 复用Canvas图片节点，避免每帧删除和重新创建。
- 隐藏的Webview暂停动画帧更新，减少后台绘制。
- 补齐构建依赖与忽略规则，源码上传不带密钥、临时档或二进制。

## 后续可优化
- 同角色动作帧的脚部基线和尾巴连续性仍可进一步手工精修。
- 小屋与桌面互动记录目前分别保存，可统一为单个本地存储。
- 加入可选托盘和透明无边框模式；保留明确退出入口。
- Windows EXE引入Pillow后体积较大，可精简打包依赖。


## 0.5.0 · 桌面文档助手
- 桌面直接配置Chat Completions接口、模型、API Key；Windows用户加密保存。
- 通过主动发送进行聊天，可选择附带最多3段本地资料。
- 导入文件或文件夹，支持TXT/MD/源码/PDF/DOCX；上限200篇、单文件5MB，跳过链接与常见密钥文件。
- 本地搜索和知识库副本管理；支持永久删除选中副本、清空全部副本，均需确认；不删除原文档。
- 扫描PDF暂无OCR，图片文字需先转为文本。网络请求不自动重试，等待期间可继续使用宠物。

- 用户补充：新增原文件/文件夹永久删除入口；完整路径确认并输入DELETE；强制模式仅解除只读，拒绝系统目录和链接。测试只删除临时样本。
