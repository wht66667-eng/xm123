# fox 陪伴插件实施记录

目标：在用户给予的最多8小时内完善现有VS Code插件及Windows桌面宠物，实际验证后本机安装。

## 设计方向
平台：现有VS Code Webview与独立Windows桌面窗口。基础：现有CommonJS扩展，不引入第二套UI组件库。角色是主视觉，奶油白与暖橙作为fox身份，中文使用系统字体。温柔、灵动、专注；陪伴动作应轻盈，支持减少动画、安静模式及退出。

## 范围
1. 本机角色状态与持久记忆：称呼、互动、学习次数、专注时间；不伪造真实情感或AI能力。
2. 插件角色之家：原创可动画角色、摸头、投喂、休息、专注计时、学习记录；与现有手动解析/建议状态联动。
3. Windows桌面宠物：可拖动、可置顶、可关闭，菜单与角色动作；独立启动，不强制开机自启。
4. 手动AI聊天入口：明确用户发送才联网，仍使用用户自己配置的接口；严禁从聊天记录读取旧密钥。
5. 测试状态保存、计时与取消、通信边界；真实VS Code扩展加载；桌面启动与界面检查；打包VSIX及本机安装，更新中文说明。
