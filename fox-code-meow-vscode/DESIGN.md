# fox 手账版实施方向

用户已确认design/fox-ui-proposal.png。平台为Windows原生Qt桌宠与助手、VS Code Webview。复用PySide6与现有CommonJS扩展，无新UI框架。

视觉：温柔、灵动、清晰。奶油白 #FFF8EF，蜜桃橘 #F18850，鼠尾草绿 #CDD7B6，可可棕 #614538。中文系统字体，标题使用衬线字形；轻插画衬底只用于陪伴内容，不遮挡操作。主任务先聊天和读取资料；狐狸头像、双向气泡、柔和按钮作为视觉锚点。

范围：桌面聊天/资料/设置/原文件管理与确认；透明桌宠保持独立。VS Code陪伴小屋同风格，保留终端解析/建议、接口密钥配置、知识库、桌宠启动。严禁打开页面自动调用AI。

内容：连接徽章只显示配置状态，不伪造联网成功；文档列表使用真实导入数据；删除需完整路径与确认。提案图片中的样例数据不写入产品。

验证：单元与集成测试，桌面四页与确认弹窗真实渲染，VS Code扩展主机与Webview检查，重新打包EXE和VSIX并安装本机。记录未验证项，保留MIT署名fox及第三方声明。
