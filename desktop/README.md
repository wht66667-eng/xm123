# fox 电脑端

- `original-training-safety-v1.0.0.exe`：用户提供的原始「实训安全教育考试系统v1.0.0.exe」，仅改存储文件名，内容不变。未运行、未改写，功能与版权属于原作者。
- `fox-safety-desktop.exe`：根据本仓库根目录 Python 控分源码打包的 Windows 命令行程序。双击运行，不需要安装 Python，按提示选择学校、登录并设置目标分数。

两者连接不同平台；原始 EXE 不包含新控分改造。fox 电脑版支持等分值试卷控分，无法保证实际成绩，规则见仓库 README。该版本是控制台交互程序，尚无原生图形窗口。

fox 电脑版未购买 Windows 代码签名证书；打包和静态归档检查不代表已通过真实平台账号测试。题库为内置副本，运行时解压到临时目录，练习增量不保证跨进程保存。
